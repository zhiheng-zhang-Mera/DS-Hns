# Frozen v38 formal public-source collection protocol

Frozen 2026-10-27 before first formal API call. Collector: scripts/ecq-v38/collection/collect.py. Eight independently stratified workflow paths across six projects: pytest-dev/pytest test.yml; fastify/fastify ci.yml and integration.yml; pallets/flask tests.yaml; nodejs/undici ci.yml and nodejs.yml; psf/requests run-tests.yml; encode/httpx test-suite.yml. Related Undici families remain one project for uncertainty.

Cutoff is exclusive 2026-10-27T00:00:00Z (start of the named UTC date). Completed success and failure strata only. Within each family and conclusion, select newest created_at, breaking ties by descending numerical run ID. Exclude every run ID appearing anywhere in the preflight JSON run lists or jobs cache, including zero-job filenames; preserve exclusion IDs and hashes of every cache JSON. Take first 15 remaining records per conclusion: first five development, next ten evaluation. Target 240 total (80 development, 160 evaluation). Do not replace zero jobs, missing source, UNKNOWN execution identity, unsupported syntax or any adverse observation. Search at most ten 100-run pages per stratum and report deficits.

Selection is saved before fetching selected-run evidence. Each selected run's run_attempt from frozen list metadata is used for the exact attempts/{attempt}/jobs endpoint, paginated in 100-job pages until total_count is reached, bounded at twenty pages. Changing totals, errors, empty premature pages or excess rows mean incomplete evidence. A legitimate total_count of zero is complete empty evidence. Updated detail metadata is retained separately and cannot silently change the selected attempt.

Retain head source as an immutable snapshot, never automatically as executed root identity. Fetch root candidate snapshots at same-repository referenced reusable SHA and commit parents as consistency witnesses. REST metadata does not independently establish the root workflow_sha, so root execution identity remains UNKNOWN absent a stronger independent witness. Do not infer PR author from actor, or historical PR event payload from current API state. Record event_name/head metadata and mark historical event payload UNKNOWN. No whole-workflow authorization claim follows from this archive alone. Source/guard support, mapping, coverage and acceptance require separate later denominators.

Fetch contents only with immutable 40-hex SHA; decode base64 source and hash bytes. Recursively fetch caller-local reusables at the candidate caller snapshot SHA and remote reusables only when explicitly pinned to a 40-hex SHA, bounded at depth three; preserve unpinned/depth/path errors as UNKNOWN. No workflow shell, action, external command or third-party CI is executed. Source snapshots from head and execution candidates stay distinct. No automatic conversion of immutable head-source closure to execution-source closure.

Bound read-only gh api calls at 1500, with per-call timeout 75 seconds. Cache all stdout response bytes including JSON errors, SHA-256, endpoint, retrieval time and exit status; never persist stderr, tokens or credentials. No API writes. No commits or pushes. Groups are repository/workflow/run ID with all future transformations together; logical revision grouping repository/head_sha additionally detects cross-family/revision dependence. Split is fixed before evidence inspection. Raw response digests attest archive bytes, not producer authenticity. This collection studies job-level contracts; successful job outcomes do not certify every test step ran.

Operational note after selection was frozen: resume uses hashed cached responses and eight concurrent read-only evidence requests to bound elapsed time; selection, splits, cutoff, exclusions and adverse-record handling are unchanged. Manifest file order uses allocated request sequence; records remain selection order. A request timeout is retained as collectionError with exit code 124.
