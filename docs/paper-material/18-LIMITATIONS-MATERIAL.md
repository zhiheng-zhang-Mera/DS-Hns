# Limitations material

- Real Windows reboot: `NOT_RUN` unless the execution host permits an unattended reboot and task resumption.
- Real 24h wall-clock soak: `NOT_RUN`; virtual-time horizons must remain labeled synthetic.
- Managed-process experiment: real supervisor and protocol, stand-in watched application.
- Plugin evidence: two published Cordis packages, one generated stranger, and repository-native plugins; no ecosystem corpus.
- Performance evidence: three local-host repeats; no randomized ordering or confidence interval.
- UI evidence: visible screenshots and real clicks on selected journeys; no participant study, accessibility conformance, or exhaustive input coverage.
- Platform: Windows/Electron only, with named-pipe transport.
- External validity: no competing harness baseline and no field incident dataset.
- Novelty: no literature review establishes novelty; all titles and claims are provisional.
- Qualification: structural evidence consistency does not establish scientific validity or production reliability.
