# Methods material

The artifact is a Windows Electron/Node desktop harness. A Runtime Host owns long-lived state and exposes a per-instance named-pipe endpoint. The Electron shell derives the same identity from root, home, app name, and user-data path. Plugins enter a common manager through native, Cordis/DSH, or managed-process adapters. Capabilities are declared before activation; the controlled bridge mediates only registered services/routes.

Health Scheduler samples bounded telemetry and emits policy decisions but cannot restart. Restart Supervisor owns the external process authority and enforces readiness, backoff, attempt budget, and safe mode. Task Continuity stores checkpoints and verifies post-restart state; Work Admission can pause new work independently.

Qualification runs create a unique immutable directory. Every gate receives D-only mutable roots and records raw streams, child report, exit code, run ID, SHA, tree, branch, host, and toolchain. Published external fixtures are fetched at pinned commits and installed using their declared lockfile/package manager. A consistency pass checks identities, timestamps, verdict/exit agreement, totals, and report containment.

Fault experiments use real implementation modules with injected deaths/network failures; process acceptance uses a stand-in watched application, and soak uses virtual time. These distinctions are retained in all reports.
